# Acknowledgments

Agent Handrails was shaped through comparison with several open-source approaches to AI-assisted software engineering, including:

- [obra/superpowers](https://github.com/obra/superpowers) — strong engineering discipline and composable development skills;
- [mattpocock/skills](https://github.com/mattpocock/skills) — small, adaptable skills for real engineering;
- [github/spec-kit](https://github.com/github/spec-kit) — specification-driven development practices;
- GSD and related context-engineering systems — fresh-context execution and durable coordination artifacts;
- the broader Agent Skills / `SKILL.md` ecosystem.

Agent Handrails intentionally takes a different position: manual-first, automation-ready primitives whose orchestration must remain explicit and inspectable.

This acknowledgment does not imply endorsement by or affiliation with those projects.
