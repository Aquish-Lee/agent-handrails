# Support

Agent Handrails is a community-ready alpha, not a commercial support service.

- Usage questions, installation help, and workflow discussion: GitHub Discussions.
- Reproducible defects: use the Bug Issue form.
- Feature and design changes: use the Feature or Design Proposal form.
- Vulnerabilities: follow [SECURITY.md](SECURITY.md); never disclose them publicly first.
- Conduct reports: follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Before asking for help, include the exact tag/commit, Codex version, Python
version, OS, Plugin or Raw installation path, command output, and the narrowest
reproduction that omits secrets. Raw `.scratch/` transcripts are local; share
only redacted evidence needed to diagnose the issue.

Current supported baseline is Linux, Git, Python 3.10+, and Codex. Windows,
macOS, Jujutsu, and other agent implementations remain unverified release
claims. Responses are best effort with no guaranteed SLA.
