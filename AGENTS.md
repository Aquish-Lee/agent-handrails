# Repository guidance

## Agent skills

### Issue tracker

Temporary local development items live in `.scratch/`; durable, project-level work lives in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the repository's five canonical triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context layout rooted at `CONTEXT.md`, with architectural decisions in `docs/adr/`. See `docs/agents/domain.md`.
