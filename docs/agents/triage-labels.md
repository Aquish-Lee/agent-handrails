# Triage labels

The engineering skills use five canonical triage roles. The same strings are used in local scratch item statuses and GitHub labels.

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the item |
| `needs-info` | `needs-info` | More information is needed from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a triage role, use the corresponding repository label from this table.
