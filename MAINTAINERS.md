# Maintainers

## Lead maintainer

- Aquish (`@Aquish-Lee`) — product direction, contracts, releases, security, and community moderation.

## Responsibilities

Maintainers keep Issues triaged, review changes proportionally to risk, preserve
version/contract integrity, maintain release and security evidence, moderate
under the Code of Conduct, and communicate support boundaries honestly.

The project is currently bus-factor one. Governance and release documentation
are intentionally explicit so a future maintainer can audit and continue the
project without relying on private context.
